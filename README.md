 SkillShift 4.0 ????



Веб-платформа для предиктивного планирования производственных смен на основе AI и анализа данных существующих систем предприятия (СКУД, MES, HR).

##  О проекте
Проект разработан для хакатона «Проектирование цифрового решения для Индустрии 4.0». 
Мы используем концепцию **Software-defined IIoT**: вместо установки дорогих физических датчиков, мы анализируем логи уже существующих систем (турникеты, терминалы цеха, 1С:ЗУП).

## Технологии
*   **Big Data:** Агрегация логов СКУД и MES.
*   **AI/ML:** Random Forest для классификации рисков брака.
*   **Cloud:** Развертывание на Streamlit Community Cloud.
*   **LLM:** GigaChat/DeepSeek для генерации аналитических отчетов.

##  Структура проекта
*   `src/data_generator.py` — скрипт генерации синтетического датасета.
*   `data/raw/` — папка для хранения CSV-файлов.
*   `src/app.py` — основное приложение Streamlit.

## Как запустить
1. Клонируйте репозиторий: `git clone https://github.com/cozlo/SkillShift-4.0.git`
2. Установите зависимости: `pip install -r requirements.txt`
3. Сгенерируйте данные: `python src/data_generator.py`
4. Запустите приложение: `streamlit run src/app.py`
